# AKKE｜营销增长工作台｜交互原型

AKKE 面向全屋定制门店的营销助手产品设计原型，用于需求评审、交互验证和团队头脑风暴，不是正式生产系统。

- 状态：评审中
- 更新日期：2026-08-02
- 页面范围：35 个主页面、14 个详情页
- 公开原型：https://akke-ai.github.io/akke-ai-growth-workbench-prototype/

## 产品范围

### 01 视频增长

覆盖业务细分选择、匹配视频标注、真实素材切片、门店代言人素材、竞品爆款视频、爆款结构拆解、制作进展和成片质检。

### 02 企微销售

覆盖销售培训资料、销冠对话样本、模拟演练标注、机器人风格规则、聊天数据、真实对话质检、高频问题优化和对话插件配置。

### 03 断联召回

覆盖活动与海报管理、召回指标、客户沟通历史与七次跟进计划、知识海报和上门测量券。

### 04 企业大脑

以“任意上传企业资料”为入口，自动完成文档解析、知识抽取、模块归类和来源留证；覆盖企业核心定位、装修行业通用知识、企业独有流程与标准、AI 动态扩展模块、冲突选择和版本发布。每条业务事实的来源必须回到用户上传的原始文件、具体页码或章节段落和对应原文摘录，数据库表名不作为业务来源。对话节奏与通用销售技巧不进入企业大脑。

## 案例与数据说明

视频、企微和召回页面仍以 AKKE 专题案例与评审模拟内容为主；企业大脑已于 2026-08-02 改为生产数据支持的脱敏原型：67 份企业知识文档、362 条行业知识索引和 2,987 个检索片段用于页面结构与内容填充。

企业大脑公开页只包含适合团队评审的业务事实、统计和行业知识摘要。私人销售对话原文、完整门店地址、数据库密钥以及受限原文件不会写入仓库。206 段历史销售对话和 36 条决策规则只显示隔离状态与数量，不作为企业事实直接发布。现有生产记录缺少原文件或段落定位时，原型会明确显示“待补录”，并禁止将该事实标记为完整可追溯。

数据存取和回填规则见 [企业大脑原始资料追溯规范](product-specs/data-provenance-spec.md)。

## 更新规范

1. Figma 为设计源文件，先完成设计确认。
2. 每次评审更新使用独立版本号，例如 `V4.1`。
3. 网页实现与 Figma 页面结构、文案和交互保持同步。
4. 合并至 `main` 后更新 GitHub Pages。
5. 重要版本创建 `vX.Y-prototype` 标签并在此记录变更。
